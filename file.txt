Build ThesisMaps — a Visual Research Intelligence Platform for graduate-level thesis research at www.ThesisMaps.com. This is a full-stack Next.js 14+ application (App Router) deployed on Vercel Pro (serverless functions and CDN). Ensure a production-ready implementation with security best practices, strict typing, accessibility, and SEO optimizations.

─────────────────────────────────────────
ARCHITECTURE & STACK
─────────────────────────────────────────
Framework: Next.js 14+ with App Router (no Pages Router) — React 18, TypeScript (strict mode, no any, no JS files).  
Styling: Tailwind CSS with utility classes and CSS variables; no inline styles.  
Database: Supabase (PostgreSQL) — use Supabase client directly (no Prisma). Enable pgvector extension.  
Authentication: Firebase Authentication (email/password + Google OAuth). Use Firebase Admin SDK on server routes and Firebase client SDK in browser. Use Firebase UID (id) as the user identifier across tables. Do not use Supabase Auth (Supabase is pure DB).  
Caching: Redis via Upstash (24h TTL for metadata, shorter TTL for dynamic data like citation counts) keyed by query hash.  
Graph Engine: React Flow + D3.js force-directed layout.  
ML/NLP Microservice: Python FastAPI (hosted on Railway or Vercel Serverless); called asynchronously from Next.js API routes for tasks like semantic search (e.g. SPECTER embeddings), keyword extraction, gap detection, and draft generation.  
Monitoring: Vercel Analytics for performance metrics and Sentry for error tracking.  
Hosting: Vercel Pro (Next.js app and API routes).  
Domain: Primary domain ThesisMaps.com; configure ThesisMaps.co.uk to 301-redirect to .com (DNS-level redirect) to consolidate SEO.  
Package Manager: pnpm.

No spring/bounce animations, no delayed/staggered loading.

Middleware (middleware.ts):

Protect /admin/*: verify ID token AND check role = 'admin' in Supabase users table (see lib/admin-guard.ts). Non-admins get redirected to /dashboard.
Admin Guard (lib/admin-guard.ts):
ts
Copy
export async function requireAdmin(request: Request) {
  const token = request.headers.get('Authorization')?.replace('Bearer ', '');
  const decoded = await adminAuth.verifyIdToken(token);
  const { data: user } = await supabaseAdmin
    .from('users').select('role').eq('id', decoded.uid).single();
  if (user?.role !== 'admin') throw new Error('Forbidden');
  return decoded.uid;
}
All /api/admin/* routes must call requireAdmin() before proceeding. This enforces fine-grained API security and least-privilege access
. Validate and sanitize all inputs using Zod schemas to prevent injection attacks
.
